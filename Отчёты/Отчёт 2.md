#### Задание 1.

Напишите блок схему отправки ping с устройства на устройство.

**Условия**: В блок схеме должно быть: 
- блоки ввода данных для ip
- как минимум один цикл
- блок вывода данных
```mermaid
flowchart LR

    Start([Начало]) --> Input[/Ввести IP-адрес/]
    Input --> Data{{Данные:IP-адрес}}
    Data --> Send[Отправить ICMP-запрос<br>ping на указанный IP]
    Send --> Wait[Ожидать ответ]
    Wait --> Cond{Ответ получен<br>в течение таймаута?}

    Cond -->|Да| Success[/Вывести: "Устройство доступно"<br>и время отклика/]
    Cond -->|Нет| Fail[/Вывести: "Устройство недоступно"/]

    Success --> Stop([Конец])
    Fail --> Stop
```

#### Задание 2.

Вспомните как работает протокол ospf, а в частности его алгоритм поиска кратчайшего пути. Составьте блок-схему отправки сообщения с одного устройства до другого, которые объединены несколькими маршрутизаторами с ospf протоколом.

**Условия**: В блок схеме должно быть: 
- должно быть как минимум одно условие
- должен быть как минимум один цикл
- должна быть как минимум одна определённая переменная
```mermaid
flowchart TD

    Start([Начало]) --> Data[/Ввести IP получателя/]
    Data --> Init[Роутер = текущий<br>Таблица маршрутов = база OSPF]
    Init --> LoopStart{Есть ли <br>маршрут до цели?}

    LoopStart -->|Да| Forward[/Отправить пакет <br>на следующий роутер/]
    LoopStart -->|Нет| Error[/Вывести: "Маршрут не найден"/]

    Forward --> NextHop[Роутер = следующий узел]
    NextHop --> Cond{Достигнут <br>получатель?}

    Cond -->|Да| Success[/Вывести:"Доставлено"/]
    Success --> Stop([Конец])
    Cond -->|Нет| LoopStart
    
    Error --> Stop
```

#### Задание 3.

Вспомним как работает протокол ssh. Составим блок-схему подключения одного узла к другому через ssh

**Условия**: 
- Должно быть условие проверки пароля
- У пользователя есть 3 попытки ввода пароля
- Должны быть блоки ввода и вывода информации

```mermaid
flowchart TD

    Start([Начало]) --> Data[/Ввести IP-адрес и имя пользователя/]
    Data --> Init[Попытки = 0<br>Максимум попыток = 3]

    Init --> LoopStart{Попытка < 3?}
    LoopStart -->|Да| InputPass[/Ввести пароль/]
    InputPass --> Check{Пароль верный?}

    Check -->|Да| Success[/Вывести: "Подключение установлено"/]
    Success --> Stop([Конец])

    Check -->|Нет| Inc[Попытки = Попытки + 1]
    Inc --> Msg[/Вывести: "Неверный пароль"/]

    LoopStart -->|Нет| Fail[/Вывести: "Доступ запрещён.<br> Превышено число попыток"/]
    Fail --> Stop
```
