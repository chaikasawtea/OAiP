#### Задание 1.

Напишите Sequence-диаграмму отправки ping-запроса на сервер.

**Условия**: В диаграмме должно быть:
- Запрос и ответ от сервера
```mermaid
sequenceDiagram

    participant Client as Клиент (устройство)
    participant Server as Сервер

    Note over Client: Пользователь запускает ping
    Client ->>Server: ICMP Rcho Request (ping)
    Note right of Server: Сервер принимает запрос
    Server -->>Client: ICMP Echo Reply (ответ)
    Note over Client: Отображение времени отклика
```

#### Задание 2.

В теоретической части рассматривался пример авторизации на сайте. Напишите подобную sequence-диаграмму авторизации на сайте, но с двойной аутентификацией.

**Условия**: В диаграмме должно быть:
- Ввод пароля
- Двойная аутентификация (например по смс)
```mermaid
sequenceDiagram

    participant User as Пользователь
    participant Site as Сайт (сервер)
    participant SMS as SMS-шлюз

    User ->>Site: Ввод логина и пароля
    Note right of Site: Проверка пароля
    Site -->>User: Пароль верный, запрос 2FA
    Site->>SMS: Отправить код подтверждения
    SMS-->>User: SMS с кодом
    User->>Site: Ввод кода из SMS
    Note right of Site: Проверка кода
    Site-->>User: Доступ разрешен(вход выполнен)
```

#### Задание 3.

Представьте что вы кассир в Пятерочке. К вам приходит покупатель с покупками. Визуализируйте вашу работу с покупателем и кассой.

**Условия**: 
- Должно быть как минимум 4 объекта
```mermaid
sequenceDiagram

    participant Buyer as Покупатель
    participant Cashier as Кассир
    participant POS as Касса
    participant Bank as Банк

  

    Buyer->>Cashier: Передает товары
    Cashier->>POS: Сканирует штрих-коды
    POS-->>Cashier: Сумма к оплате
    Cashier-->>Buyer: Озвучивает сумму
    Buyer->>Cashier: Оплата картой
    Cashier->>POS: Провести оплату
    POS->>Bank: Запрос на списание
    Bank-->>POS: Подтверждение оплаты
    POS-->>Cashier: Чек напечатан
    Cashier-->>Buyer: Отдаёт товары и чек
```
