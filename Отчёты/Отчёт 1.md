## Задание 2 
Написать Блок-схему "Поход в магазин".
**Условия**: В блок схеме должно быть: 
- не меньше 10 процессов.
- не меньше 5 условий.
- не меньше 1 цикла.
- не меньше 1 блока данных.

```mermaid
flowchart TD

Start([Поход в магазин]) --> A[Составить список покупок]
A --> Data[(Список покупок:<br>Название, кол-во, отметка)]
Data --> B[Взять деньги/карту]
B --> C[Взять сумку/корзинку]
C --> D[Выйти из дома]
D --> E[Дойти до магазина]
E --> F[Войти в магазин]

F --> Cond1{Нужна тележка?}
Cond1 -->|Да| Process7[Взять тележку]
Cond1 --> |Нет| Process8[Взять корзину]
Process7 --> LoopStart[Начало цикла]
Process8 --> LoopStart 

LoopStart --> Cond2{Все ли куплено<br> по списку?}
Cond2 -->|Да| Process9[подойти к кассе]
Cond2 -->|Нет| Proccess10[Пройти по отделам<br>и найти товар]

LoopStart --> Cond3{Всё ли куплено<br>по списку?}
Cond3 -->|Да| Process11[Взять товар<br>и отметить в списке]
Cond3 -->|Нет| Process12[Заменить аналогом<br>или пропустить]

Process11 -->LoopEnd[Конец цикла]
Process12 --> LoopEnd
LoopEnd --> LoopStart

Process9 --> Cond4{хватает денег?}
Cond4 -->|Да| Process13[оплатить покупки]
Cond4 -->|Нет| Process14[Убрать часть товаров<br>обратно на полку]
Process14 --> Process9

Process13 --> Process15[Убрать товары в сумку]
Process15 --> Process16[Выйти из магазина]
Process16 --> Process17[Вернуться домой]
Process17 --> Process18[Разложить продукты]
Process18 --> Finish([Конец])
```

- Суммирование

#### Вариант 1
Найти сумму всех целых чисел от А до B включительно (Подразумевается ввод А и Б от пользователя)

**Условие**: А < B

*Пояснение*: Нужно использовать цикл для перебора всех чисел от А до B и накопления суммы (Создайте переменную для суммы с помощью блока процесса)

```mermaid
flowchart TD

    Start([Начало]) --> Input[/Ввести A и B/]
    Input --> Data{{Данные:A,B}}
    Data -->Cond{A < B?}
    
    Cond --> |Нет| Error[/"Ошибка: А должно быть меньше В"/]
    Error --> Stop([Конец])
    Cond -->|Да| Sum[S = 0<br>i = A]
    Sum --> LoopStart{i <= B?}

    LoopStart -->|Да| Add[S = S+i]
    Add --> Inc[i = i+1]
    Inc --> LoopStart

    LoopStart -->|Нет| Output[/Вывести S/]
    Output --> Stop
```
